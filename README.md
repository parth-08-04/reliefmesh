RELIEFMESH

AI-Assisted Disaster Response and Resource Coordination Platform

RELIEFMESH is a web-based platform designed to improve disaster response by connecting affected citizens, volunteers, NGOs and emergency coordinators.

Problem

During disasters, emergency information and relief resources are often scattered across different communication channels. This makes it difficult to verify requests, identify urgent needs and coordinate assistance.

Our Solution

RELIEFMESH provides a centralised platform for:

- Emergency reporting
- AI-assisted report analysis
- Duplicate report suggestions
- Disaster location mapping
- NGO resource management
- Volunteer coordination
- Resource matching
- Relief delivery tracking

Technology Stack

- React + Vite
- Tailwind CSS
- Supabase
- AI API
- OpenStreetMap + Leaflet

User Roles

1. Citizen
2. Volunteer
3. NGO
4. Coordinator / Administrator

Team

Developed by a team of six students for the HackWithAditya 2026 Open Innovation track.
